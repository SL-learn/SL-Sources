## 逐条记录

### ♻️🎌异世界动漫（`std_jar_vod_dmmiku`）

- 形态：jar（`csp_Ysj`，`jar: ./spider.jar`）
- 首次发现：2026-11-08
- 失败层：详情
- 失败证据：**详情异常·挂起 122s**——真机探针 `HUNG|std_jar_vod_dmmiku|detail|122631`（122.631 秒），同轮 `PROBE|stage detail 43364ms ERR(IndexOutOfBoundsException: Index: 0, Size: 0)`；分类正常（2 类：新番 / 完结），故异常被「分类 OK」掩盖。
- 根因（字节码与页面证据）：
  1. `csp_Ysj` 的 `detailContent(List)` 在字节码 pc `0x0007` 先取 `ids.get(0)`，本机入参为 `Collections.singletonList(vid)`，非空，**不是入参空数组**。
  2. 异常发生在 pc `0x01c6`（异常栈 `Unknown Source:454` = 十进制 454 = 0x1c6）：`m.L("li.data")` 返回 0 个节点后直接 `AbstractList.get(0)`，抛 `Index: 0, Size: 0`。
  3. 选择器与站点已从 `Ysj.short` 解密确认：base `https://www.dmmiku.com/`，详情页取 `li.data`、`ul.content_playlist.clearfix`、`li.desc.hidden_xs`；`li.data` 缺失即页面为空或改版。
  4. 上游可达性：宿主直连 `https://www.dmmiku.com/` 与 `/index.php/vod/type/id/22.html` 均连接/读取超时；本轮复跑（18:22）首页 45 秒 `TIMEOUT`。即详情拿到的是空/不完整页面，`li.data` 匹配为空，jar 侧无空判 → 抛异常并挂起。
- 结论：脚本对空页面缺保护属第三方混淆 jar（`spider.jar`）缺陷，无法改；上游响应超时为服务端问题。**不可修，摘出成品**。
- 当前状态：观察中；下次复测：2026-11-11
- 备份：`备份/std_jar_vod_dmmiku.json`
- 用户裁决：待裁决（保持观察或永久删除）
