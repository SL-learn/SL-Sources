## 2. 站点名与 key 冲突

| 冲突类型 | 处置 | 影响范围 |
|---|---|---|
| 站点显示名带公号/emoji/全角符号 | 按 R-NAM-17 清洗：去 emoji、去全角符号、去首尾空白，超过 10 字截断 | 全部 151 站 |
| 清洗后重名 | 追加序号尾缀（如 `-2`），保持长度 ≤10 | 无新增重名（A10 校验通过） |
| 原 key 含中文或大写 | 按 R-NAM-05 重排四段式；ASCII 部分小写后作短名；无可用 ASCII 的用 `s<序号>` | 综合线约 28 站、少儿/长辈线少量 |

## 3. 文件与 jar 冲突

| 冲突对象 | 处置 | 落位 |
|---|---|---|
| 多来源线路同名脚本 `drpy2.min.js` | 先到先得；后到者加来源前缀 | `SL 少儿线路/api/drpy2.min.js`、`SL 长辈线路/api/huban_drpy2.min.js`、`SL 长辈线路/api/jiduo_drpy2.min.js` |
| 多来源同名规则 `douban.json` | 后到者加来源前缀 | `SL 综合线路/json/huban_douban.json` |
| 多线路引用同一 jar | 统一放 `_common/jar/<来源>_<md5前8>.jar`；线路内以 `../_common/jar/` 引用 | `_common/jar/` 共 12 个 jar |
| 顶层 spider 必须本地可加载 | 每线路取引用次数最多的 jar 复制为 `spider_<代号>.jar` | 各线路目录根 |
| 远端 jar（gitee / clewm） | 下载后按内容 hash 命名放入 `_common/jar/`，不保留远端地址 | 已本地化，无跨域引用 |

## 4. 内容门禁处置

| 对象 | 处置 |
|---|---|
| 成人主体源 | 未请求、不入候选、不转存（R-GAT-02） |
| 含成人分类的上游 CMS | 改走 `SL 综合线路/js/cms.js` 包装；`home` 不上架、`category` 返回空、搜索与详情二次过滤（R-CFG-15/16） |
| 存量站点 `categories` 白名单含成人词 | 逐条剔除成人项；剔除后为空则删字段（R-GAT-06） |
| 规则 json 中的成人筛选项 | 递归删除 `{n,v}` 命中词表的选项，其余结构不动 |
| jar 二进制字符串扫描 | 12 个 jar 对 `伦理/理论片/三级/里番/写真/福利/情色/无码/有码/擦边/两性/自拍/偷拍` 扫描，**0 命中** |
| 6 条网盘/工具站点 | 删除，不入包（R-GAT-04） |
| 4 条间歇性源 | 删除，不入包（用户决策） |
| AcFuns | 无分类数组，判无法判定，不入包（README 12.1） |
| 巨量资源 | 上游为 XML CMS，现版包装只解析 JSON，按 R-CFG-18 不降级直连，本轮不入包 |
