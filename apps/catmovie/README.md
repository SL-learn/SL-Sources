# catmovie 应用导览（小猫影视）

单文件全量配置，客户端填一个地址即可加载。

本仓为公开子集，只发布经过实测的公开源；完整清单与内部记录不随仓库发布。

## 入口

`https://raw.githubusercontent.com/SL-learn/SL-Sources/main/apps/catmovie/config.json`

## 当前内容（1.4.1）

公开点播源 **19 条**、直播源 **6 条**。点播 19 条满足四段实测：分类可解析、≥2 个分类有片、详情播放地址可解析、首地址真拉到视频数据。

配置顶层含 `updateTime` 字段（`YYYY-MM-DD HH:MM`），最后更新时间同时记录在同目录 `更新时间.txt`。

排序：先按播放判档（流畅 → 一般 → 卡），同档内按接口速度档位；卡的源不与流畅源混排。名称档位只允许 `极速/快速/标准/慢速` 四个值；本轮三端点耗时凑不齐均值的源不写档位，只保留内容名，待可测时再补。

## 配置行为说明

- **不写 `extra.category`**：分类由客户端读取上游 `ac=list` 的 `class` 得到。参考文档对该字段的定义（分类筛选字符串）与「静态分类数组」的用法存在歧义，未在真机证实，故不依赖它。
- 分类按上游原样展示，不重排、不加后缀。
- 慢速源不因速度剔除；判档为「卡」的源保留并按 `慢速` 命名，集中在列表末段。
- 名称档位只允许 `极速/快速/标准/慢速`；未测得三端点算术均值的源不写档位，避免出现 `间歇` 这类非法前缀。
