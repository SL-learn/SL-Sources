tvbox 包 v2.3.1
================

定位
----
个人自用影视源包，三条线路：综合 / 少儿 / 长辈。
包内不含直播源（lives 为空），不含付费与网盘站点。

三个入口，别填错
----------------
文件名                适用场景                         填法
api_index_local.json  整包拷到手机，本地离线用          clan://localhost/tvbox/api_index_local.json
api_index.json        在线直拉（raw，含 jar 引用）       https://raw.githubusercontent.com/SL-learn/SL-Sources/main/apps/tvbox/api_index.json
api_all.json          客户端不支持多线路索引时          https://raw.githubusercontent.com/SL-learn/SL-Sources/main/apps/tvbox/api_all.json

关于 jsDelivr：
- api_all.json 可换用 https://cdn.jsdelivr.net/gh/SL-learn/SL-Sources@main/apps/tvbox/api_all.json
  （它内部全部是绝对 raw 地址，CDN 只负责下发这一份 JSON）。
- api_index.json 不要换 jsDelivr：线路配置用 ./spider.jar 这类相对引用，会跟着解析到 CDN，
  而 jsDelivr 对 .jar 一律返回 403（实测两次均 403），导致整条线路加载失败。

三种入口的区别：
- api_index_local.json 用 clan:// 指向本地三条线路，不联网；整包必须放在 /sdcard/TVBox/tvbox/。
- api_index.json 只含三条线路地址（绝对 URL），选线路后各自加载，站点分开管理。
- api_all.json 把三条线路 64 个站点合成一份，只有一个站点列表；适合不认 urls 索引的客户端。

安装（本地，推荐）
------------------
1. 把整个 apps/tvbox 目录下的内容放到手机存储：/sdcard/TVBox/tvbox/
   目录名必须保持 tvbox，不能改名。
2. 打开 TVBox → 设置 → 配置地址，填：
   clan://localhost/tvbox/api_index_local.json
3. 客户端识别出 3 条线路并自动加载第一条（综合线路）。
4. 设置页出现「线路」一行，点开即可在 综合 / 少儿 / 长辈 之间切换。

在线直链
--------
把 api_index.json 的 raw 地址填入配置地址即可，无需下载整包。
在线与本地内容一致，区别只在入口写法。

重要：路径里不要用百分号编码
----------------------------
线路目录已改为 ASCII 短名（std / kids / elders），
索引里不要再写中文目录名，也不要写 SL%20%E7%BB%BC 这类百分号编码。

线路与站点数
------------
- std（综合）：52 站
- kids（少儿）：4 站
- elders（长辈）：8 站
- api_all.json 合计：64 站

名称标记怎么看
--------------
- 🔎 该源没有分类页，请直接到搜索框搜片名使用。
- ♻️ 该源可能失败，失败时重试一次或换个关键词。
- ⚡ / ⏱ / 🐢 响应速度：快 / 一般 / 慢。

环境限制（不是源失效）
----------------------
另有 5 条 py 源与 13 条 ARM jar 源未收录：
- 5 条 py 需客户端带 Python 引擎；
- 13 条 ARM jar 需 ARM 设备才能加载其 .so。
两者均属环境限制、尚未验证，不等于源失效；换 ARM 设备或对应客户端包后可再验。

目录说明
--------
_common/jar/       公共 jar，线路内以 ../_common/jar/xxx.jar 引用
_common/md5.txt    jar 校验清单（文件名,md5,大小）
std/ kids/ elders/ 三条线路目录，各含 api.json、spider.jar（固定名）与 js/py/open/ext/lib/api/config
version.json       包版本与线路登记（客户端不读取）

内容屏蔽
--------
含成人分类的上游 CMS 源一律经 js/cms.js 包装后入包：
- home() 不上架成人分类与非影视分类；
- category() 命中成人分类直接返回空列表；
- homeVod()/search()/detail() 再按名称二次过滤。
包装脚本按站点 key 映射上游地址，不依赖 ext。

版本与校验
----------
版本：2.3.1（2026-11-08）
配置顶层带 updateTime 字段（格式 YYYY-MM-DD HH:MM），客户端忽略该键；
同目录 更新时间.txt 记录本次改动。
所有 jar 引用均带 ;md5;，md5 见 _common/md5.txt 与各 api.json。
