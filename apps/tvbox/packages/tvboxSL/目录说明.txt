tvboxSL 本地包 v1.0.0
=====================

定位
----
个人自用影视源包，三条线路：综合 / 少儿 / 长辈。
包内不含直播源（lives 为空），不含付费与网盘站点。

安装（本地）
------------
1. 把整个 tvboxSL 目录放到手机存储：/sdcard/TVBox/tvboxSL/
   目录名必须保持 tvboxSL，不能改名。
2. 打开 TVBox → 设置 → 配置地址，填：
   clan://localhost/tvboxSL/api_index.json
3. 客户端识别出 3 条线路并自动加载第一条（综合线路）。
4. 设置页出现「线路」一行，点开即可在 综合 / 少儿 / 长辈 之间切换。

在线直链
--------
api_index.json 的 raw 地址即为配置地址；三条线路的单独地址见 api_index.json 内的 urls。

线路与站点数
------------
- SL 综合线路（std）：123 站
- SL 少儿线路（kid）：17 站
- SL 长辈线路（eld）：11 站

目录说明
--------
_common/jar/       公共 jar，线路内以 ../_common/jar/xxx.jar 引用
_common/md5.txt    jar 校验清单（文件名,md5,大小）
spider_<代号>.jar  该线路顶层入口 jar（必须存在，否则整份配置加载失败）
api.json           该线路唯一配置
js/ py/ open/ ext/ lib/ api/ config/   该线路脚本与规则

内容屏蔽
--------
含成人分类的上游 CMS 源一律经 js/cms.js 包装后入包：
- home() 不上架成人分类与非影视分类；
- category() 命中成人分类直接返回空列表；
- homeVod()/search()/detail() 再按名称二次过滤。
包装脚本按站点 key 映射上游地址，不依赖 ext。

版本：1.0.0（2026-11-07）
所有 jar 引用均带 ;md5;，md5 见 _common/md5.txt 与各 api.json。
