tvboxSL 包 v1.0.1
=====================

定位
----
个人自用影视源包，三条线路：综合 / 少儿 / 长辈。
包内不含直播源（lives 为空），不含付费与网盘站点。

三个入口，别填错
----------------
文件名                适用场景                       填法
api_index_local.json  整包拷到手机，本地离线用        clan://localhost/tvboxSL/api_index_local.json
api_index.json        在线直拉（GitHub 可访问时）     https://raw.githubusercontent.com/SL-learn/SL-Sources/main/apps/tvbox/packages/tvboxSL/api_index.json
api_all.json          客户端不支持多线路索引时        https://raw.githubusercontent.com/SL-learn/SL-Sources/main/apps/tvbox/packages/tvboxSL/api_all.json

区别：
- api_index_local.json 用 clan:// 指向本地三条线路，不联网；整包必须放在 /sdcard/TVBox/tvboxSL/，目录名不能改。
- api_index.json 只含三条线路地址（绝对 URL），选线路后各自加载，站点分开管理。
- api_all.json 把三条线路 151 个站点合成一份，只有一个站点列表；适合不认 urls 索引的客户端。

安装（本地，推荐）
------------------
1. 把整个 tvboxSL 目录放到手机存储：/sdcard/TVBox/tvboxSL/
   目录名必须保持 tvboxSL，不能改名。
2. 打开 TVBox → 设置 → 配置地址，填：
   clan://localhost/tvboxSL/api_index_local.json
3. 客户端识别出 3 条线路并自动加载第一条（综合线路）。
4. 设置页出现「线路」一行，点开即可在 综合 / 少儿 / 长辈 之间切换。

在线直链
--------
把 api_index.json 的 raw 地址填入配置地址即可，无需下载整包。
在线与本地内容一致，区别只在入口写法。

重要：路径里不要用百分号编码
----------------------------
线路目录名含中文和空格（如 SL 综合线路）。索引里必须写原样的中文，
不要写成 SL%20%E7%BB%BC...；本地文件服务不解码百分号，写编码会 404，
表现为「选了线路但站点是空的」。

线路与站点数
------------
- SL 综合线路（std）：123 站
- SL 少儿线路（kid）：17 站
- SL 长辈线路（eld）：11 站
- api_all.json 合计：151 站

目录说明
--------
_common/jar/       公共 jar，线路内以 ../_common/jar/xxx.jar 引用
_common/md5.txt    jar 校验清单（文件名,md5,大小）
spider_<代号>.jar  该线路顶层入口 jar（必须存在，否则整份配置加载失败）
api.json           该线路唯一配置
js/ py/ open/ ext/ lib/ api/ config/   该线路脚本与规则

内容屏蔽
--------
含成人分类的上游 CMS 源一律经 js/cms.js 包装后入包：
- home() 不上架成人分类与非影视分类；
- category() 命中成人分类直接返回空列表；
- homeVod()/search()/detail() 再按名称二次过滤。
包装脚本按站点 key 映射上游地址，不依赖 ext。
