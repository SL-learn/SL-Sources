# reading 应用（阅读 / Legado）

阅读（Legado）可直接导入的成品。本目录只放成品，规则、模板、样例不放这里。

## 目录（仅 5 个文件）

| 路径 | 内容 |
|---|---|
| `书源.json` | 书源成品，JSON 数组，UTF-8 无 BOM；条数见 `version.json` |
| `订阅源.json` | 订阅源成品，JSON 数组，UTF-8 无 BOM；条数见 `version.json` |
| `更新时间.txt` | 第一行最后更新时间，第二行本次改动说明 |
| `README.md` | 本说明 |
| `version.json` | 版本、条数与 `updatedAt` 登记 |

书源与订阅源是纯 JSON 数组，**不支持文件头字段**；最后更新时间见每条源备注字段末尾的 `更新：YYYY-MM-DD` 行，以及 `version.json` 的 `updatedAt`、`更新时间.txt`。

配套文件在仓库级目录，不在本应用目录内：

| 用途 | 位置 |
|---|---|
| 字段与校验判据 | `规范/阅读书源校验规则.md`、`规范/阅读订阅源校验规则.md` |
| 最小骨架模板 | `工具/阅读模板/书源模板.json`、`工具/阅读模板/订阅源模板.json` |
| 字段源码基线 | `参考资料/阅读3.0-hectorqin` 提交 `da17bb2` 的 `BookSource.kt`、`RssSource.kt` |

### 成人源 `⑱` 规则

- 成人源名称前统一加 `⑱ `，分组统一为 `⑱ 成人`，只存在于非公开域台账，**不进公开仓、不给公开地址**。
- 公开包内 `⑱` 命中数必须为 0；`⑱ 成人` 组不得出现在 `apps/reading/` 的任何文件里。


## 导入步骤（可直接复制地址）

书源与订阅源是**两类分别导入**，两个地址各填一次。地址由 `工具/发布/渲染.py` 从 `规则/平台地址.json` 生成：

<!-- 地址块开始：由 工具/发布/渲染.py 生成，勿手改 -->
| 类别 | 填到软件哪个入口 | GitHub 地址 | Gitee 地址 |
|---|---|---|---|
| 书源（101 条） | 书源管理 → 网络导入 | `https://raw.githubusercontent.com/SL-learn/SL-Sources/main/apps/reading/书源.json` | 451 拦截，暂不可用 |
| 订阅源（22 条） | 订阅 → 网络导入 | `https://raw.githubusercontent.com/SL-learn/SL-Sources/main/apps/reading/订阅源.json` | 451 拦截，暂不可用 |

> 书源与订阅源**分两次导入**，两个地址各填一次，不能合并成一个包。Gitee 侧两个文件都被 451 拦截，暂只能用 GitHub 地址或下载文件后本地导入。
<!-- 地址块结束 -->

- 书源：阅读 → 我的 → 书源管理 → 右上角 ⋮ → 网络导入 → 填上表书源地址。
- 订阅：阅读 → 我的 → 订阅 → 右上角 ⋮ → 网络导入 → 填上表订阅源地址。
- 也可以下载 `书源.json`、`订阅源.json` 后分别用「本地导入」选文件导入。

## 发布门禁

公开域扫描无阻断项。成品为第三方导入源整包，字段集与仓库自建源规范不同；门禁只对违规内容做阻断，规范项差异记录在本机 `工具/源检测/记录/` 报告（一次性证据，不入库），不据此删条。
