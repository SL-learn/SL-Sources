# reading 应用（阅读 / Legado）

阅读（Legado）可直接导入的书源与订阅源成品，以及配套的校验规则、模板。

## 目录

| 路径 | 内容 |
|---|---|
| `书源.json` | 书源成品，**115 条**，JSON 数组，UTF-8 无 BOM |
| `订阅源.json` | 订阅源成品，**27 条**，JSON 数组，UTF-8 无 BOM |
| `校验/书源校验规则.md` | 书源字段清单与校验判据 |
| `校验/订阅源校验规则.md` | 订阅源字段清单与校验判据 |
| `模板/书源模板.json` | 最小书源骨架 |
| `模板/订阅源模板.json` | 最小订阅源骨架 |
| `version.json` | 版本与条数登记 |

根目录下的 `.json` 都是可直接导入的成品；校验规则与模板只放在 `校验/`、`模板/` 子目录，避免与成品混淆。

## 条数与更新

- 书源：115 条，更新日期 2026-11-08。
- 订阅源：27 条，更新日期 2026-11-08。
- 本地验证版另有 117 条书源 / 28 条订阅；公开仓按合规要求剥离了 2 条成人域书源（ESJ Zone、西瓜书屋 R18）与 1 条成人域订阅（Lvmao影院），其余逐条一致。
- 每条书源保留名称前的分类图标（如 🌐、📚、🎉），导入后按名称即可区分类型。
- `customOrder` 连续且从 1 开始，**导入后的顺序就是质量顺序**，靠前优先。
- `bookSourceUrl` 全批唯一，无重复；无 `null`/空对象条目。

## 导入步骤

- 书源：阅读 → 我的 → 书源管理 → 右上角 ⋮ → 本地导入 → 选 `书源.json`，一次选中整包导入。
- 订阅：阅读 → 订阅 → 右上角 ⋮ → 本地导入 → 选 `订阅源.json`。

## 成人源

成人书源、成人订阅源**不入库**，只在使用者本地私有目录单独维护，按同样的「本地导入」方式加载。本仓库 `书源.json`、`订阅源.json` 均不含成人内容；公开域扫描结果为成人标记 0 条、私有域条目 0 条。

## 校验与模板

`校验/` 下的字段判据来自本地源码 `参考资料/阅读3.0-hectorqin`（提交 `da17bb2`）的 `BookSource.kt`、`RssSource.kt`；`模板/` 只保留最小骨架，供新增条目时复制。

成品为第三方导入源整包，字段集与仓库自建源规范（顶层字段齐全、命名正则、分组白名单、注释四段登记）不同；发布门禁只对成人主体源与私有域内容做阻断，规范项差异逐条记录在 `工具/源检测/记录/` 本地报告，不据此删条。
