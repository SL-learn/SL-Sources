# reading 应用导览（阅读 / Legado）

仓库只放**规则、模板与说明**；个人在用的 `书源.json`、`订阅源.json` 属个人数据，不入公开仓。

## 提交了什么

| 路径 | 内容 |
|---|---|
| `书源/模板.json` | 最小书源骨架，复制后填 `bookSourceUrl` 等字段 |
| `书源/校验规则.md` | 书源字段清单与校验判据（字段行号对 `da17bb2`） |
| `订阅源/模板.json` | 最小订阅源骨架 |
| `订阅源/校验规则.md` | 订阅源字段清单与校验判据（字段行号对 `da17bb2`） |
| `version.json` | 规则版本登记 |

## 没提交什么、为什么

| 未提交 | 原因 |
|---|---|
| 个人 `书源.json` | 个人数据，含自用站点与账号配置，公开会泄露来源与隐私 |
| 个人 `订阅源.json` | 同上 |
| 抓取的正文/缓存 | 版权内容，仓库不做内容存储 |

个人源由使用者自行生成、自行保管、本地导入；仓库只提供生成它所需的模板与判据。

## 个人源怎么自行加载

1. 复制 `书源/模板.json`，按 `书源/校验规则.md` 填字段，保存为 `书源.json`。
2. 复制 `订阅源/模板.json`，保存为 `订阅源.json`。
3. 阅读 App → 我的 → 书源管理 → 右上角菜单 → 本地导入，选择文件即可。
4. 多个书源用 JSON 数组 `[{...},{...}]` 包起来；单个书源可以直接是一个对象。

## 字段基线

订阅源字段行号来自本地源码 `参考资料/阅读3.0-hectorqin`（`da17bb2`）的
`app/src/main/java/io/legado/app/data/entities/RssSource.kt`；书源来自同目录 `BookSource.kt`。
不带行号依据的字段一律不写进模板。
