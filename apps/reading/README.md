# reading 应用（阅读 / Legado）

阅读（Legado）可直接导入的成品。本目录只放成品，规则、模板、样例不放这里。

## 目录（仅 5 个文件）

| 路径 | 内容 |
|---|---|
| `书源.json` | 书源成品，**111 条**，JSON 数组，UTF-8 无 BOM |
| `订阅源.json` | 订阅源成品，**26 条**，JSON 数组，UTF-8 无 BOM |
| `更新时间.txt` | 第一行最后更新时间，第二行本次改动说明 |
| `README.md` | 本说明 |
| `version.json` | 版本、条数与 `updatedAt` 登记 |

书源与订阅源是纯 JSON 数组，**不支持文件头字段**；最后更新时间见每条源备注字段末尾的 `更新：YYYY-MM-DD` 行，以及 `version.json` 的 `updatedAt`、`更新时间.txt`。

配套文件在仓库级目录，不在本应用目录内：

| 用途 | 位置 |
|---|---|
| 字段与校验判据 | `规范/阅读书源校验规则.md`、`规范/阅读订阅源校验规则.md` |
| 最小骨架模板 | `工具/阅读模板/书源模板.json`、`工具/阅读模板/订阅源模板.json` |
| 字段源码基线 | `参考资料/阅读3.0-hectorqin` 提交 `da17bb2` 的 `BookSource.kt`、`RssSource.kt` |

## 条数与更新（v1.5.0，2026-11-08 17:46）

- 书源：111 条；订阅源：26 条。
- 全部书源按 7 组归组、全部订阅源按 5 组归组，**每条源只对应一个组**（不再出现 `源仓库,小说 书源` 这类多标签分组）。
- 同组内名称唯一：重名条目第 2 条起加 `·备`、`·备2`；同一 host 的重复后端已合并（本轮 `📚书海阁子` 3 条并为 1 条）。域名差异写备注，不写进名称。
- 每条源备注字段（`bookSourceComment` / `sourceComment`）末尾保留 `更新：2026-11-08` 标记，不改动原有备注内容。
- 每条书源备注新增一行 `来源：…；上游：…；作者：…`，不可核实处写 `未标注`；判组有争议的条目追加 `判定：…`，备用条目追加 `备用：主入口域名 X，本入口域名 Y`。
- 本仓只收录公开子集，不包含私有清单内容；条数以 `version.json` 为准。
- 每条书源保留名称前的历史分类图标（🌐、📚、🎉 等），仅作历史标记；**分组以 `bookSourceGroup` 为准**。
- `customOrder` 连续且从 1 开始，**导入后的顺序就是质量顺序**。
- `bookSourceUrl` 全批唯一，无重复；无 `null`/空对象条目。

### 书源 7 组与条数

| 组 | 条数 | 收什么 |
|---|---|---|
| 📚 小说 | 80 | 只提供网络小说的站点/接口（含女频、玄幻、轻小说等单品类或全小说品类站，但不含出版书城） |
| 🔍 综合 | 6 | 可搜多品类或非小说的聚合站/工具站（社区、词典、荐书接口、影视站） |
| 🖼 漫画 | 5 | `bookSourceType=2` 的图片源 |
| 🎧 有声 | 1 | `bookSourceType=1` 的音频源 |
| 📖 出版 | 17 | 正版/签约书城与付费 APP 平台（sfacg、多看、晋江、书旗、纵横、起点、潇湘、书耽、UC 等） |
| ♻️ 间歇 | 2 | 客户端可重试的间歇性故障源（名称带 ♻️） |
| ⑱ 成人 | 私有台账 | 成人源，公开仓不收录 |

判组口径：能搜全品类书的聚合站归「🔍 综合」；只提供小说的归「📚 小说」；正版/付费书城归「📖 出版」；判不清的按实际搜索返回的书籍类型定组，依据写进备注 `判定：`。组内按客户端搜索命中条数降序、再按 `respondTime` 升序排列。

### 成人源 `⑱` 规则

- 成人源名称前统一加 `⑱ `，分组统一为 `⑱ 成人`，只存在于私有台账，**不进公开仓、不给公开地址**。
- 公开包内 `⑱` 命中数必须为 0；`⑱ 成人` 组不得出现在 `apps/reading/` 的任何文件里。


## 导入步骤

- 书源：阅读 → 我的 → 书源管理 → 右上角 ⋮ → 本地导入 → 选 `书源.json`，一次选中整包导入。
- 订阅：阅读 → 我的 → 订阅 → 右上角 ⋮ → 本地导入 → 选 `订阅源.json`。

## 发布门禁

公开域扫描无阻断项。成品为第三方导入源整包，字段集与仓库自建源规范不同；门禁只对违规内容做阻断，规范项差异记录在 `工具/源检测/记录/` 本地报告，不据此删条。
