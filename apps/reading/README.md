# reading 应用（阅读 / Legado）

阅读（Legado）可直接导入的成品。本目录只放成品，规则、模板、样例不放这里。

## 目录（仅 4 个文件）

| 路径 | 内容 |
|---|---|
| `书源.json` | 书源成品，**115 条**，JSON 数组，UTF-8 无 BOM |
| `订阅源.json` | 订阅源成品，**27 条**，JSON 数组，UTF-8 无 BOM |
| `README.md` | 本说明 |
| `version.json` | 版本与条数登记 |

配套文件在仓库级目录，不在本应用目录内：

## 条数与更新（v1.2.0，2026-11-08）

- 书源：115 条；订阅源：27 条。内容与 v1.1.0 一致，本版只做目录结构整理。
- 本地验证版另有 117 / 28 条，多出的 3 条成人域条目按合规要求不入公开仓，见下文「成人源」。
- 每条书源保留名称前的分类图标（🌐、📚、🎉 等），导入后按名称即可区分类型。
- `customOrder` 连续且从 1 开始，**导入后的顺序就是质量顺序**。
- `bookSourceUrl` 全批唯一，无重复；无 `null`/空对象条目。

## 导入步骤

- 书源：阅读 → 我的 → 书源管理 → 右上角 ⋮ → 本地导入 → 选 `书源.json`，一次选中整包导入。
- 订阅：阅读 → 我的 → 订阅 → 右上角 ⋮ → 本地导入 → 选 `订阅源.json`。

## 成人源（不入库，本地私有目录）

公开仓剥离的成人域条目，统一放在仓库同级私有域，目录与公开结构镜像：

| 文件 | 内容 |
|---|---|
| `私有域/apps/reading/书源-成人.json` | 成人书源，含公开仓剥离的成人域条目与本地成人池全量 |
| `私有域/apps/reading/订阅源-成人.json` | 成人订阅源，含公开仓剥离的成人域条目与本地成人池全量 |

条目构成与加载说明见 `私有域/apps/reading/README.md`。

加载方式：与普通包相同——阅读 → 我的 → 书源管理（或订阅）→ 右上角 ⋮ → 本地导入，选中对应成人文件即可。私有域只在本机维护，不推送到公开仓、不提供公网地址。

## 发布门禁

公开域扫描结果：成人标记 0 条、私有域条目 0 条。成品为第三方导入源整包，字段集与仓库自建源规范不同；门禁只对成人主体源与私有域内容做阻断，规范项差异记录在 `工具/源检测/记录/` 本地报告，不据此删条。
