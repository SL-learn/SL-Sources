# 书源校验规则

基线：`参考资料/阅读3.0-hectorqin` 提交 `da17bb2`
字段定义：`app/src/main/java/io/legado/app/data/entities/BookSource.kt`

## 必填与唯一性

| 字段 | 行号 | 判据 | 不满足 |
|---|---|---|---|
| `bookSourceUrl` | 34 | 非空、`http(s)://` 开头、同批内唯一（主键语义） | 阻断 |
| `bookSourceName` | 36 | 非空、2–20 字、同组内不重名 | 阻断 |
| `bookSourceType` | 41 | 取 `BookSourceType` 枚举：0 文本 / 1 音频 / 2 图片 / 3 下载站（`constant/BookSourceType.kt:8-11`） | 阻断 |
| `enabled` | 49 | 布尔；公开模板固定 `true` | 提示 |
| `enabledExplore` | 52 | 布尔；有 `exploreUrl` 时应为 `true` | 提示 |

## 入口

| 字段 | 行号 | 判据 |
|---|---|---|
| `searchUrl` | 87 | 非空；含 `{{key}}` 占位；`http(s)://` 或 `/` 开头 |
| `exploreUrl` | 81 | 可为空；非空时需同时有 `ruleExplore` 或分类规则可用 |
| `ruleSearch` | 89 | 对象，至少含 `bookList`、`name`、`bookUrl` |
| `ruleBookInfo` | 91 | 对象，至少含 `name`、`intro` |
| `ruleToc` | 93 | 对象，至少含 `chapterList`、`chapterName`、`chapterUrl` |
| `ruleContent` | 95 | 对象，至少含 `content` |

## 内容与合规

| 判据 | 说明 |
|---|---|
| 禁止成人站点 | URL、名称命中成人词表即阻断 |
| 禁止网盘/盘搜 | URL 或名称命中网盘词即阻断 |
| 禁止内嵌登录凭据 | `loginUrl`/`header` 不得含 token、cookie、账号密码 |
| 禁止本地路径 | 字段里不得出现 `file://`、`./`、盘符路径 |

## 结构校验

| 项 | 判据 |
|---|---|
| JSON 可解析 | 单对象或对象数组，UTF-8 无 BOM |
| 字段拼写 | 只允许 `BookSource.kt` 中存在的字段；未知字段记「可疑」并列出 |
| 空规则 | `ruleSearch`/`ruleToc`/`ruleContent` 全空视为空壳，不算可用书源 |
| 重复 | 同批 `bookSourceUrl` 重复即阻断 |

## 校验顺序

1. 解析 JSON。
2. 必填与非空。
3. 枚举与布尔取值。
4. 词表门禁。
5. 规则完整性。
6. 输出：阻断项、可疑项、通过项三类。
