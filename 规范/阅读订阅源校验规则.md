## 合规与结构

| 判据 | 说明 |
|---|---|
| 禁止成人站点 | 仅针对公开域文件：URL、名称命中成人词表即阻断；成人订阅源另存非公开文件，不参与公开域校验 |
| 禁止凭据 | `loginUrl`/`loginUi`/`header` 出现账号、token、cookie 即阻断 |
| 禁止本地路径 | 不得出现 `file://`、`./`、盘符路径 |
| JSON 可解析 | 单对象或对象数组，UTF-8 无 BOM |
| 字段拼写 | 只允许 `RssSource.kt` 中存在的字段；未知字段记「可疑」 |
| 空壳判定 | `ruleArticles` 与 `ruleLink` 同时为空视为空壳，不算可用订阅源 |

## 校验顺序

1. 解析 JSON。
2. 必填与非空。
3. 枚举与布尔取值。
4. 词表门禁。
5. 抓取规则完整性。
6. 输出：阻断项、可疑项、通过项三类。
