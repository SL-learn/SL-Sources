## 2. 客户端事实基线（TVBox）

本章只陈述**源码可证**的行为，作为后续所有规则的前提；不再在其它章节重复。

| 编号 | 事实 | 依据 |
|---|---|---|
| TVB-CFG-001 | `type` 取值：`0`=XML CMS，`1`=JSON CMS，`3`=爬虫（jar/js/py），`4`=remote，`-1`=内置 `push_agent` | `ApiConfig.java` 解析分支 |
| TVB-CFG-002 | `type:3` 的加载器按 `api` 后缀分流：`.js`/`.js?` → JsLoader；含 `.py` → pyLoader；其余 → JarLoader（**不校验扩展名**，`.jpg`/`.png` 伪装的 jar 可加载） | `ApiConfig.java:1456-1470` |
| TVB-CFG-003 | jar 加载：`DexClassLoader`；类名必须在 `com.github.catvod.spider.` 下；`api` 含 `csp_` 时取后半段；`;md5;` 之后为校验值 | `JarLoader.java` |
| TVB-CFG-004 | jar 缓存文件为 `cacheDir/jar/<md5(jar地址)>.jar`。**带 md5**：本地文件 md5 一致才复用，否则重下；**不带 md5**：缓存 3 天内有效 | `JarLoader.java:196-230`、`FileUtils.isWeekAgo`（实为 3 天） |
| TVB-CFG-005 | 顶层 `spider` 由 `downloadJarAsync` 用 OkHttp `Request.url(url)` 下载，只接受 http(s)；本地需先经 `fixContentPath` 转成 http 才可用 | `ApiConfig.java:438-458` |
| TVB-CFG-006 | `configUrl()`：`file://` → `clan://localhost/`；含 `;pk;` 时拆出密钥；`clan` 开头 → `clanToAddress`；其余非 http 前缀补 `http://` | `ApiConfig.java:170-192` |
| TVB-CFG-007 | `clanToAddress()`：`clan://localhost/<路径>` → `http://127.0.0.1:<端口>/file/<路径>`；端口默认 9978，被占用时递增 | `ApiConfig.java:1773-1781`、`ControlManager` |
| TVB-CFG-008 | `clanContentFix()`：仅当**配置 URL 以 `clan` 开头**时，把配置内容里的 `clan://localhost/`、`file://` 前缀替换成本机 http 基址 | `ApiConfig.java:383-393、1783-1786` |
| TVB-CFG-009 | `fixContentPath()`：仅当配置内容含 `"./` 或 `"../` 时执行；先替换 `../`，再替换 `./`；基准是**配置自身的 URL** | `ApiConfig.java:1788-1798` |
| TVB-CFG-010 | 本地文件服务：请求路径以 `/file/` 开头时，取其后半段拼到外部存储根，**不做 `..` 防穿越校验** | `RemoteServer.java:158-166` |
| TVB-CFG-011 | Python：插件名取 `url` 末段去扩展名；`file://` 前缀会被直接去掉，导致本地路径失效；**必须写 `./py/x.py`**；每次 init 都会重新下载 | `pyramid/src/python/app.py` |
| TVB-CFG-012 | `lives[].type` 只接受 `"0"`、`"3"`；其它值会导致直播分组被清空后直接返回 | `ApiConfig.java:1384-1387` |
| TVB-CFG-013 | 多线路索引只认 `{"urls":[{"url","name"}]}`（兼容纯字符串数组）；JSON 中含 `sites` 或没有 `urls` 时**不视为索引** | `ApiConfig.java:671-703` |
| TVB-CFG-014 | 识别到索引后自动加载第一条，并写入线路列表；直接加载子配置会因 `clearApiLinesIfUnmatched` 清空线路列表 | `ApiConfig.java:650-669、728-739` |
| TVB-CFG-015 | 客户端只有一份当前配置（`API_URL` 单键）；不同包不会同时并列显示，只能通过接口历史切换 | `HawkConfig.API_URL` |
| TVB-CFG-016 | 配置每次启动都尝试拉取，只有拉取失败才回退本地缓存 | `HomeActivity` 调用 `loadConfig(useCache=false)` |
| TVB-CFG-017 | 本地文件服务把请求路径**原样**拼到存储根，不做百分号解码；路径里带 `%E7%BB%BC` 这类编码会 404，表现为「选了线路但站点为空」。因此 v2.0.0 起线路目录改用 ASCII 短名 `std`/`kids`/`elders`，从根上不再依赖中文路径 | `RemoteServer.java:158-166`；历史故障见 `记录/2026-11-07/tvbox/探活报告.md` |
| TVB-CFG-018 | jsDelivr 对 `.jar` 一律返回 403（连续两次实测），只适合下发 JSON；因此在线索引必须走 raw，不能换 CDN | 实测 `cdn.jsdelivr.net/gh/.../xingwei_df5bf731.jar` → 403；同路径 JSON → 200 |
| TVB-CFG-019 | **主客户端 = 影视仓**（包名 `com.huawei.himovceie`，v6.2.9，CatVod 派生）。其 Java 侧调用 js 源的 `homeContent`/`categoryContent`/`detailContent`/`searchContent`/`playerContent`，且 `detailContent` 入参为数组；不调用 TVBox 的 `home`/`homeVod`。脚本必须同时导出两套命名 | 影视仓 6.2.9 dex 字符串 + 其 `assets/js/lib/spider.js` 加载包装实测 |

【待验证】以下一项需实机确认，验证方法写在括号内：
1. `UriUtil.resolve(<含中文空格的配置URL>, "../")` 的返回值是否等价于「上一级目录」（临时把一条 jar 站点指向 `../_common/jar/` 的空壳 jar，看是否 200）。

（原第 2 项「NanoHTTPD 是否解码百分号」已由 TVB-CFG-017 定性为不解码，转为规则。）

## 4. 目录与命名

### 4.1 包内结构（以 `apps/tvbox` 为例）

```text
apps/tvbox/
├── version.json                   ← 包 id、版本、状态、线路清单
├── api_index.json                 ← 在线入口：三条线路的绝对 URL
├── api_index_local.json           ← 本地入口：三条线路的 clan:// 地址
├── api_all.json                   ← 单文件全量（151 站），绝对 URL
├── 目录说明.txt                    ← 用户安装说明
├── _common/
│   ├── jar/                       ← 公共 jar（ASCII 文件名）
│   └── md5.txt                    ← jar 校验清单
├── std/                    ← 线路目录（ASCII 短名，路径冻结）
│   ├── api.json
│   ├── spider.jar
│   ├── js/  py/  open/  ext/  lib/
├── kids/
└── elders/
```

| 路径 | 用途 | 进版本库 | 客户端是否加载 |
|---|---|---|---|
| `version.json` | 包版本与线路登记 | 是 | 否 |
| `api_index.json` | 在线多线路入口（绝对 URL） | 是 | 是（作为配置地址） |
| `api_index_local.json` | 本地多线路入口（`clan://`，中文原样） | 是 | 是（整包拷到手机后使用） |
| `api_all.json` | 单文件全量配置（三线合一） | 是 | 是（不支持 `urls` 索引的客户端） |
| `目录说明.txt` | 给人看的安装说明 | 是 | 否 |
| `_common/jar/*.jar` | 跨线路共用的 jar | 是 | 是（被 `sites[].jar` 引用） |
| `_common/md5.txt` | jar 校验清单 | 是 | 否 |
| `<线路>/api.json` | 该线路唯一配置 | 是 | 是 |
| `<线路>/spider.jar` | 顶层 `spider` 入口（固定名） | 是 | 是 |
| `<线路>/js/ py/ open/ ext/ lib/` | 该线路独占脚本与引擎 | 是 | 是（被 `api`/`ext` 引用） |
| `.gitkeep` | 占位空目录 | 是 | 否 |

|---|---|---|---|

| TVB-NAM-003 | 线路配置 | 固定 `api.json`，不得改名 | `api.json` |
| TVB-NAM-004 | 索引文件 | 固定 `api_index.json` | `api_index.json` |
| TVB-NAM-005 | 站点 key | 四段式 `<线路代号>_<形态>_<用途>_<短名>`；正则 `^(std|kid|eld)_(jar|js|py|cms)_(vod|live|tool)_[a-z0-9]{2,12}$`，总长 8–32 | `std_jar_vod_xingxing` |
| TVB-NAM-006 | 入口 jar | 固定 `spider.jar`（三条线路各自目录内同名，不带线路代号与版本号） | `std/spider.jar` |
| TVB-NAM-007 | 公共 jar | `<来源>_<角色或内容hash8>.jar`，全 ASCII，禁中文/空格/括号 | `xingwei_main.jar`、`ouge_6f1e49c3.jar` |

### 4.3 路径引用写法

目录名全部 ASCII（TVB-NAM-002），索引与线路引用都不再涉及中文与百分号编码。

| 场景 | 写法 |
|---|---|
| 在线索引 | `https://raw.githubusercontent.com/<owner>/SL-Sources/main/apps/tvbox/std/api.json` |
| 本地索引 | `clan://localhost/tvbox/std/api.json` |
| 线路内引用 | `./js/x.js`、`./py/x.py`、`../_common/jar/x.jar` |

| 编号 | 规则 |
|---|---|
| TVB-NAM-013 | 索引里的线路地址：在线写绝对 raw URL、本地写 `clan://localhost/<本地根名>/<线路目录>/api.json`；一律写 ASCII 原样，禁止百分号编码、禁止 `./` 相对写法（相对写法依赖客户端解析，实测会失败） |
| TVB-NAM-014 | 线路内脚本引用写 `./js/x.js`、`./py/x.py`；公共 jar 写 `../_common/jar/x.jar`；不得写 `file://` |
| TVB-NAM-015 | 顶层 `spider` 写 `./spider.jar;md5;<32位小写>`；不得依赖 `clan://` |
| TVB-NAM-016 | 站点 `name`、`flags` 中禁止出现 `"./` 与 `"../` 字符序列（会被 `fixContentPath` 当路径替换）；`api`、`ext`、`jar` 反而**必须**用相对路径，由 `fixContentPath` 正常改写（TVB-NAM-014） |
| TVB-NAM-017 | 站点 `name` 清洗：去 emoji、去全角符号、去首尾空白；长度 2–10 字；清洗后撞名按第 13 章处理。内容符号与速度符号是 TVB-NAM-022/023 规定的例外，不受本条「去 emoji」约束 |
| TVB-NAM-018 | 站点 `name` 的速度档位只由速度符号表达（TVB-NAM-023）；不再写 `-快`/`-中`/`-慢` 汉字后缀 |
| TVB-NAM-019 | 速度档位以实测耗时为唯一依据，取值来自体检表 `记录/<日期>/tvbox/源体检表.csv` 的「三次均值ms」列；无实测数据的站点不得标档位，也不得凭印象标档位 |
| TVB-NAM-020 | 本地入口固定文件名 `api_index_local.json`，内容为 `clan://` 三条线路；在线入口固定 `api_index.json`，内容为绝对 URL；两者除 url 写法外必须完全一致 |
| TVB-NAM-021 | 单文件全量配置固定文件名 `api_all.json`，把三条线路 `sites` 合并；所有 `api`/`jar`/`ext` 一律写绝对 raw URL，`;md5;` 段不得编码；`key` 与线路内保持完全一致 |
| TVB-NAM-022 | 内容符号固定枚举，一个站点只取一个：`🎬` 综合影视、`🎞` 电影、`📺` 剧集、`🎤` 综艺、`🎌` 动漫、`🎭` 短剧、`🎠` 少儿、`⚽` 体育、`📚` 听书/曲艺、`🩺` 养生/生活；不得自造符号 |
| TVB-NAM-023 | 速度符号固定枚举：`⚡` ≤1500 ms、`⏱` 1500–4000 ms、`🐢` ≥4000 ms；未实测或结论为「需复测」的站点不加速度符号 |
| TVB-NAM-024 | 站点 `name` 格式固定为 `<内容符号><清洗名><速度符号>`；清洗名按 TVB-NAM-017 处理、去掉既有速度后缀；同线路内撞名追加 `·2`、`·3`（追加在清洗名之后、速度符号之前）。例外：仅搜索型（无分类页、只能搜索使用）在速度符号之后追加 `🔎`；间歇源（可能失败、需重试）在名称最前置 `♻️` |
| TVB-NAM-025 | 线路内排序：先按内容符号固定次序（TVB-NAM-022 的枚举顺序），再按速度档 `⚡`→`⏱`→未实测→`🐢`，最后按原数组顺序稳定排序；重排只改 `name` 与顺序，`key` 一律不改。例外：仅搜索型整组排到线路后段；`♻️` 间歇源排在同组末尾 |

**不满足的处理**：出现百分号编码的中文目录、`file://`、`"./` 冲突序列中任一项，该文件判不合格，不进入验收。

## 5. TVBox 配置格式（`api.json`）

### 5.1 必填与可选字段

| 字段 | 必填 | 取值与规则 |
|---|---|---|
| `spider` | 是 | `./spider_<代号>.jar;md5;<32位小写>`；骨架阶段允许空串 |
| `sites` | 是 | 数组，可为空；顺序即 UI 顺序 |
| `lives` | 是 | 数组，可为空 |
| `parses` | 是 | 数组，可为空 |
| `flags` | 是 | 字符串数组，可为空 |
| `wallpaper` | 否 | 图片 URL，留空 |
| `ijk` | 否 | 播放器选项，本仓不配置 |

### 5.2 `sites[]`

| 字段 | 必填 | 规则 |
|---|---|---|
| `key` | 是 | 符合 TVB-NAM-005；全配置唯一；禁用 `push_agent` |
| `name` | 是 | 格式 `<内容符号><清洗名><速度符号>`（TVB-NAM-024）；清洗名 2–10 字（TVB-NAM-017） |
| `type` | 是 | `0`/`1`/`3`；CMS 实测返回 JSON 用 `1`，XML 用 `0`（见 TVB-CFG-027） |
| `api` | 是 | `type:3` 时：jar 写 `csp_<类名>` 或 `csp_<类名>;md5`（由 `jar` 决定载体）；js 写 `./...js`；py 写 `./py/x.py`。`type:0/1` 时写上游 CMS 地址 |
| `jar` | 视情况 | `type:3` 的 jar 站点必填，写 `../_common/jar/x.jar;md5;...`；不得为空 |
| `searchable` | 是 | `0`/`1`；列表型 CMS 才允许 `1` |
| `quickSearch` | 是 | `0`/`1`；未验证搜索能力一律 `0` |
| `changeable` | 否 | `0`/`1`，默认 `1`；`0` = 不参与详情页换源（`ApiConfig.java:767`） |
| `ext` | 否 | 短字符串；禁止路径序列（TVB-NAM-016）；禁止换行与首尾空白 |
| `playerType` | 否 | 与 `parses[].flag` 对应的播放器标记，不填即默认 |

> 站点级**没有** `filter` 字段：客户端只读 `searchable`、`quickSearch`、`changeable`、`filterable`（`ApiConfig.java:765-772`）。`filterable` 只写不读（无 `getFilterable` 调用点），写了无效，禁止用于表达其它含义。CMS 的分类筛选能力由上游 `?ac=list` 返回的 `class` 决定，不靠站点字段配置。

### 5.3 `lives[]`

| 字段 | 必填 | 规则 |
|---|---|---|
| `name` | 是 | 中文分组名 |
| `url` | 是 | m3u/txt 地址；只允许 http(s) |
| `type` | 是 | **只能是 `"0"` 或 `"3"`**（TVB-CFG-012） |
| `playerType` | 否 | 默认 `0` |
| `ext` | 否 | 仅 `type:"3"` 使用，指向 py 解析 |
| `ua` | 否 | 上游要求特定 UA 时填写 |
| `epg` | 否 | EPG 地址 |

### 5.4 `parses[]` 与 `flags[]`

- `parses[]` 每项：`name`、`type`（`0` 嗅探 / `1` 解析）、`url`、`ext{flag,header}`。
- `flags[]` 写 `parse_<源>`、`m3u8_<源>`、`vip_<平台>` 三类命名族；`sites[].playerType` 必须能在 `flags` 或 `parses` 中找到对应。

### 5.5 格式与取值硬规则

| 编号 | 规则 |
|---|---|
| TVB-CFG-019 | 严格 JSON：无注释、无尾逗号、无 BOM；UTF-8 |
| TVB-CFG-020 | 禁止 `type:-1` 与 `key:"push_agent"` |
| TVB-CFG-021 | 禁止 `lives[].type` 取 `"0"`/`"3"` 以外的值 |
| TVB-CFG-022 | 所有 jar 引用必须带 `;md5;<32位小写十六进制>` |
| TVB-CFG-023 | 单个配置文件 ≤512 KB；脚本单文件 ≤1 MB |
| TVB-CFG-024 | 站点总数：单线路 ≤300；超出必须拆线或拆包 |
| TVB-CFG-025 | 同一 `api` 的站点不得重复出现（同源异名按第 13 章合并） |
| TVB-CFG-026 | `sites` 顺序：① jar 主力 ② js 主力 ③ py 主力 ④ CMS 备用 ⑤ 工具/解析；首个站点必须是该线路最稳定主力 |
| TVB-CFG-027 | CMS 的 `type` 以实测响应为准：`ac=list` 返回 `{` 开头用 `1`，返回 `<?xml`/`<rss` 用 `0`；不得按惯例猜 |
| TVB-CFG-028 | `ext` 只放短标识或 JSON 字符串，不放路径、不放 URL（需要 URL 时写进专门字段） |

**不满足的处理**：TVB-CFG-019/TVB-CFG-020/TVB-CFG-021/TVB-CFG-022 任一项违反 → 该线路判不合格，阻断发布；其余项记入待修清单，下一版修正。

### 5.6 成人分类封闭（JS 包装）

**事实基线**（源码可证）：

| 编号 | 事实 | 依据 |
|---|---|---|
| TVB-CFG-029 | 站点级 `categories` 是**正向白名单**，按 `type_name` 精确匹配过滤分类列表；它只影响首页/切源后的分类 Tab，**不改变内容可访问性** | `DefaultConfig.adjustSort()`、`HomeActivity.java:340/342/970` |
| TVB-CFG-030 | 全链路只有 `adjustSort` 一处分类过滤点，因此白名单可被**搜索、首页推荐、`type_flag` 以 `1` 开头的文件夹下钻**绕过 | 同上 |
| TVB-CFG-031 | `hide` 字段在本 fork 不存在；`filterable` 只写不读；`filters` 只作用于分类内部，不作用于分类列表 | `ApiConfig.java:765-782` |

## 6. 多线路与索引

### 6.1 索引结构

```json
{
  "urls": [
    { "name": "综合", "url": "./SL%20%E7%BB%BC%E5%90%88%E7%BA%BF%E8%B7%AF/api.json" },
    { "name": "少儿", "url": "./SL%20%E5%B0%91%E5%84%BF%E7%BA%BF%E8%B7%AF/api.json" },
    { "name": "长辈", "url": "./SL%20%E9%95%BF%E8%BE%88%E7%BA%BF%E8%B7%AF/api.json" }
  ]
}
```

| 编号 | 规则 |
|---|---|
| TVB-STR-001 | 索引只能含 `urls` 数组；不得含 `sites`，否则不被识别（TVB-CFG-013） |
| TVB-STR-002 | 每条必须有 `name` 与 `url`；`name` 即「线路选择」里显示的名字 |
| TVB-STR-003 | 第一条必须是该包最稳定线路（加载即进入它） |
| TVB-STR-004 | 线路显示名与线路目录中文一致：综合 / 少儿 / 长辈；不得同名重复 |
| TVB-STR-005 | 索引内线路地址必须相对（`./`），编码按 TVB-NAM-013；不得写域名 |
| TVB-STR-006 | 新增线路 = 新建线路目录 + 索引加一条 + `version.json` 加一条；不得改既有线路 |
| TVB-STR-007 | 禁止让用户直接添加子线路 `api.json` 作为「多线路」用法：未先加载索引时会清空线路列表（TVB-CFG-014）；子配置仅作单线备用入口，需在说明中标明 |

**不满足的处理**：索引含 `sites`、第一条不可用、显示名重复，任一项命中则整包不发布。

## 7. 资源与公共库复用

### 7.1 结论

| 资源 | 位置 | 理由 |
|---|---|---|
| jar | 包内 `_common/jar/` | 跨线路唯一重复的大文件，共用可省约 11.9 MB；`JarLoader` 直接解析相对路径 |
| js | 各线路自己的 `js/`/`open/`/`lib/` | `JsLoader` 没有 `clan://` 分支，且剧本常带相对依赖，跨目录易断 |
| py | 各线路自己的 `py/` | Python 侧会剥掉 `file://`，只认 `./` 相对；且每次 init 重下，跨目录引用无收益 |
| 图片 | 各线路自己的 `img/` | 体积小，不值得共用 |

| 编号 | 规则 |
|---|---|
| TVB-STR-008 | 公共 jar 只放包内 `_common/jar/`；不得放仓库级共享目录，不得放线路目录 |
| TVB-STR-009 | 站点引用公共 jar 一律写 `../_common/jar/<文件>.jar;md5;<32位>` |
| TVB-STR-010 | 同一 jar 在包内只允许一份；确需两个版本时，另一份放需要它的线路目录内，不得共用 |
| TVB-STR-011 | `_common/md5.txt` 必须登记每个 jar 的 md5、字节数与引用线路代号；未登记视为不合格 |
| TVB-STR-012 | jar 文件名全 ASCII；伪装成 `.jpg`/`.png` 的 jar 必须改名为 `.jar` 后在 `md5.txt` 备注原扩展名 |
| TVB-STR-013 | 公共 jar 内每个被 `api` 引用的类名必须真实存在；发布前逐个核对 |
| TVB-STR-014 | 未使用（无任何 `api` 引用）的 jar 不得留在 `_common/jar/` |

**不满足的处理**：TVB-STR-008/TVB-STR-010/TVB-STR-011 违反 → 整包不合格；TVB-STR-013 违反 → 对应站点下线。

## 12. 探活标准

### 12.1 分形态探法

| 形态 | 探什么 | 成功判据 | 判定上限 |
|---|---|---|---|
| CMS（`type` 0/1） | `<url>?ac=list`；失败再试 `<url>?ac=list&at=json` | 200 且可解析且分类数 ≥1 | 每对象 2 次 |
| jar（`type:3`） | 不做网络探活；静态检查：文件存在、含 `classes.dex`、被引用类名存在 | 三项全过 | 静态 |
| js（`type:3`） | 剧本 URL | 200、≥5 KB、文件头不是 `<html` | 每对象 2 次 |
| py（`type:3`） | 剧本 URL | 200、非 HTML 落地页 | 每对象 2 次 |

### 12.2 执行口径

| 编号 | 规则 |
|---|---|
| TVB-PRB-001 | 连接超时 5 s、读取超时 10 s；总耗时上限 10 s/次 |
| TVB-PRB-002 | 每对象最多 2 次请求；相邻请求间隔 ≥1 s；单对象单次维护 ≤3 个请求 |
| TVB-PRB-003 | 只打列表/分类接口；不打搜索、不打详情、不下载播放地址 |
| TVB-PRB-004 | 不并发轰炸同一上游；同一域名下对象串行 |
| TVB-PRB-005 | UA 固定 `okhttp/3.15`，与客户端一致 |
| TVB-PRB-006 | 失败不追加第三次；连续两次失败即停 |

### 12.3 四档结论与死亡判定

| 结论 | 判据 |
|---|---|
| 可用 | 两次均成功，或一次成功且响应完整 |
| 间歇 | 一次成功一次失败；或成功但字节数明显异常（<1 KB） |
| 不可用 | 两次均失败，且有明确证据：DNS 失败、连接被拒、404/410、持续 5xx、返回 HTML 落地页 |
| 无法判定 | 无有效探测入口（纯 jar）、或响应为空但无错误 |

| 编号 | 规则 |
|---|---|
| TVB-PRB-007 | 判「上游死亡」需同时满足：连续两个维护周期（间隔 ≥24 h）均失败 + 错误类型属于 DNS/域名过期/TLS/404/410/持续 5xx |
| TVB-PRB-008 | 单次 502/超时/0 字节只判「间歇」，不得据此判死 |
| TVB-PRB-009 | 纯 jar 包没有 CMS 入口，只能记「无法判定」；不得写成「不可用」 |
| TVB-PRB-010 | 探活记录字段固定：包 id、包版本、对象名、形态、探测接口、HTTP 码、耗时 ms、字节数、分类数、重试次数、结论、证据摘要、探测时间、探测器版本 |
| TVB-PRB-011 | 每次维护必须产出三件：原始 `json`、人读 `探活报告-<包id>.md`、`探活索引.csv` 追加一行 |
| TVB-PRB-012 | 记录目录按「日期 → 应用 → 包」三层：`records/<YYYY-MM-DD>/<应用id>/<包id>.json` |
| TVB-PRB-013 | 探活索引列固定：`日期,应用id,包id,包版本,对象总数,可用,间歇,不可用,无法判定,新增失效,恢复,报告路径,原始数据路径` |
| TVB-PRB-014 | 记录默认全部保留；超过 12 个月的原 json 移入 `records/_归档/<年>/`，索引行不删 |
| TVB-PRB-015 | 探活范围覆盖**所有包的配置内站点**，不只新接入的来源 |

**不满足的处理**：缺任一记录件、结论与证据矛盾、把「无法判定」写成「可用」，该次维护判不合格，不得发布。

## 13. 修复、回归与冲突处置

### 13.1 结构可修与不可修

| 类型 | 现象 | 可修 | 修法 |
|---|---|---|---|
| 缺 md5 | jar 引用无 `;md5;` | 是 | 计算 md5 补写，更新 `md5.txt` |
| `lives.type` 非法 | 不是 `"0"`/`"3"` | 是 | 按上游实际形态改为合法值 |
| 引擎被替换 | js 引擎文件实为 HTML 错误页 | 是 | 换回正确引擎文件或改用同线可用引擎 |
| key 重复 | 同配置内 key 相同 | 是 | 加线路/来源前缀消歧 |
| 路径错误 | `../` 乱用、相对路径断 | 是 | 改为 `./` 或 `../_common/` |
| jar 缺失 | 引用文件不存在 | 是 | 补文件或改指向同内容 jar |
| 上游死亡 | DNS 失败、域名过期、404 持续 | 否 | 只下架，不伪造 |
| 需鉴权/付费 | 播放需登录、充值、扫码 | 否 | 只标注/下架，不绕鉴权 |
| 载体非配置 | 下载物是图片、网页、说明文字 | 否 | 记录证据，不进候选 |

| 编号 | 规则 |
|---|---|
| TVB-PRC-001 | 修复只做结构层；不得伪造上游响应、不得绕鉴权、不得改上游数据 |
| TVB-PRC-002 | 每条修复必须写「现象 → 根因 → 修法 → 验证方式」四段，缺一段不算修复完成 |
| TVB-PRC-003 | 修完必须复探一次；复探结论与修复前不同的，在记录中写清前后对比 |
| TVB-PRC-004 | 不可修项只下架并留证，不从候选清单中删证据 |

### 13.2 重复与冲突处置

重合度定义：上游归一化为 `scheme://host/path`（去 query、小写、去尾斜杠），对 key 集合与上游集合分别求 Jaccard，取较大值；站点名去 emoji/空格后小写仅作人工复核辅助。

| 编号 | 场景 | 判定 | 处置 | 留痕 |
|---|---|---|---|---|
| C1 | 两条线路高度重合 | 重合度 ≥60%，或同名同源 | 保留站点多、可用率高者为主线；另一条独占站点补入并标 `·备线` | 重合率、保留方、补入清单 |
| C2 | 两条线路部分重合 | 30% ≤ 重合度 < 60% | 允许并存；重复站点只留一份 | 重合率、去重数 |
| C3 | 同站点跨线路，key 相同 | 全局 key 去重 | 保留一份；两线都要用则改线路前缀 | key、涉及线路 |
| C4 | 同站点跨线路，key 不同 | 归一化上游相同 | 同源异名：留被引用多者，并列留探活更好者 | 三方对照 |
| C5 | 同源异名 | C4 判定 | 只留一个，名称取更规范者 | 同上 |
| C6 | 同名异源 | 名称归一化相同、上游不同 | 都可用则都留，名称加 `·<来源>`；只有一个可用则删另一个 | 两上游与结论 |
| C7 | 同 jar 多版本 | 按 md5 分组 | `_common` 只留一个；另一版本放需要的线路目录内 | md5、所属线路 |
| C8 | 索引重复线路/重名 | 解析后 url 去重、name 去重 | 去重；重名加 `·2`；3 条以上重复阻断发布 | 原始索引片段 |
| C9 | 新旧包并存 | 同一时刻只有一份当前配置（TVB-CFG-015） | 不视为冲突；key 带线路代号防串号 | 版本登记 |
| C10 | 名称含 emoji/特殊符号 | 清洗后撞名 | 加来源后缀，仍撞加 `·2`；key 不含特殊字符 | 原名→新名 |
| C11 | 同域不同路径 | 归一化到完整 path | 视为不同站点；内容相同则按 C4 | path 与对比结论 |
| C12 | 版本未变内容变了 | 比对 md5 清单 | 阻断发布，升版本并更新 md5 | 差异文件清单 |
| C13 | jar 被多线共用 | 正常 | 不处置，`md5.txt` 登记全部引用线 | 自动登记 |
| C14 | 清洗后名称为空 | 长度 0 | 用 key 的短名生成，或剔除 | 原名与处置 |

| 编号 | 规则 |
|---|---|
| TVB-PRC-005 | 同一规则冲突时优先级：同名同源 > 探活结论 > 站点数量 > 名称规范度 |
| TVB-PRC-006 | 每次处置必须在 `records/<日期>/<应用id>/冲突处置-<包id>.md` 留痕，并在 `冲突处置索引.csv` 追加一行 |

### 13.3 主客户端与兼容冲突处置

| 编号 | 规则 |
|---|---|
| TVB-PRC-007 | 主客户端为影视仓，TVBox 为兼容客户端。验收底线是「同一份配置在影视仓显示分类、能进片」；TVBox 不得因适配而回退 |
