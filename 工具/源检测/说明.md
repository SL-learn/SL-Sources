# 源检测 说明

位置：`工具/源检测/`｜条款依据：`规范/TVBox 源规范.md` 第 11–14 章。

## 命令

```bash
python 工具/源检测/main.py 检测 --应用 TVBox apps/tvbox/std/api.json
python 工具/源检测/main.py 检测 --应用 TVBox apps/tvbox --探活
python 工具/源检测/main.py 修复 --应用 TVBox apps/tvbox/std/api.json          # dry-run
python 工具/源检测/main.py 修复 --应用 TVBox apps/tvbox/std/api.json --执行   # 落盘
python 工具/源检测/main.py 检测 --应用 阅读 <书源文件或目录>
python 工具/源检测/main.py 检测 --应用 小猫影视 apps/catmovie/config.json
```

| 参数 | 含义 |
|---|---|
| `--应用` | `TVBox` / `小猫影视` / `阅读` / `阅读-订阅源`，决定读哪份机读规则 |
| `--域` | `公开`=成人内容阻断；`私有`=只打标。缺省取规则里的默认域 |
| `--规则` | 显式指定规则 JSON，缺省读 `规则/<应用>.json` |
| `--探活` | 启用网络探活（TVBox 按 MacCMS 口径；阅读按书源规则） |
| `--采样` | 探活条数上限，缺省取规则配置 |
| `--输出` | 报告目录，缺省 `工具/源检测/记录/<日期>/<应用>/` |
| `--记录` | 记录根目录，缺省为工具目录下的记录子目录（本地，不入公开仓） |
| `--执行` | 修复/补充默认 dry-run；只有显式 `--执行` 才落盘 |
| `--覆盖` | 覆盖原文件前自动备份到 `备份/` |

## 执行纪律

| 步骤 | 动作 | 依据 |
|---|---|---|
| 1 | 先 `检测`（无 `--执行`），只出报告 | 规范第 14 章验收清单 |
| 2 | 需要修复时人工确认，再 `--执行` | 用户要求「修复需显式确认」 |
| 3 | 落盘后看 `修复前后对比` 与 `修复结果/*.diff` | 可回滚 |
| 4 | 推送前跑一次公开域检测，成人/网盘词命中即阻断 | 门禁 R-GAT |
| 5 | 把本轮人工结论摘要抄进 `记录/YYYY-MM-DD/<应用>/`，再升版本 | 日志与变更分离 |

## 目录

| 路径 | 进公开仓 | 说明 |
|---|---|---|
| `main.py core.py probe.py record.py repair.py adapters/` | 是 | 检测实现 |
| 本工具目录下的记录目录 | 否 | 批量执行报告、明细 CSV、索引，属执行日志，留本地 |
| `规则/`（仓库根） | 是 | 机读判据正本，本工具直接读取 |

## 退出码

`0` 全部通过；`1` 存在阻断项。CI 或发布脚本以退出码判断是否放行。

## 与规范的关系

规则文件只放阈值与判据，不放解释；条款正文在 `规范/`。两者不一致时以 `规范/` 为准，并同步改 `规则/`。
