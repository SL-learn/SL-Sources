# 源生成 说明

位置：`工具/源生成/`｜条款依据：`规范/TVBox 源规范.md` 第 4、6 章，`规范/仓库通用规范.md` 第 10 章。

## 一条命令重建

```bash
python 工具/源生成/生成.py          # 生成 + 自检
python 工具/源生成/生成.py --check  # 只自检，不写文件
```

## 输入与输出

| 项 | 内容 |
|---|---|
| 唯一事实来源 | `apps/tvbox/{std,kids,elders}/api.json`。站点增删、顺序、`name`、`key` 只改这里 |
| 输出 | `apps/tvbox/api_index.json`（绝对 raw）、`api_index_local.json`（`clan://`）、`api_all.json`（151 站合并） |
| 不产出 | `version.json`、`目录说明.txt`，这两份手写并需与版本一致（SYS-VER-002） |

## 行为约定

| 项 | 约定 |
|---|---|
| 幂等性 | 生成结果与现有文件逐字节比对，相同则不重写、不改 mtime；可直接反复执行 |
| 失败回滚 | 三份输出先在内存算完再统一落盘；自检不通过则**一个文件都不写**，退出码 1 |
| 自检项 | 本地引用存在、`;md5;` 与文件一致、`spider` 存在且 md5 一致、`key` 全局唯一、`sites` 非空 |
| key 比对 | 仓库有 git 历史时，自动对比 `HEAD` 与当前各线路 `key` 集合，打印「一致 / 不一致」 |
| 路径固定 | 生成器里 `RAW`、`LOCAL_ROOT`、线路目录是常量，改路径等于改规范，必须先改 `规范/` 与 `决策记录.md` |

## 校验线上

```bash
python 工具/源生成/校验.py                    # 校验 main
python 工具/源生成/校验.py --ref tvbox-v2.0.0
```

校验项：索引 200 且 3 条线路、三线路 200 且站点数与本地一致、`spider.jar` 200 且 md5 一致、`api_all.json` 200、`cms.js` 200。

## 发布前顺序

1. 改 `api.json`（只改事实来源）。
2. `生成.py --check` 通过。
3. `生成.py` 落盘。
4. 校验脚本 `校验.py` 本地视角无失败（线上需先推送）。
5. 用 `源检测` 工具走门禁（见 `工具/源检测/说明.md`）。
6. 升版本、追加 `变更/CHANGELOG-<应用>.md` 与 `记录/版本对照表.csv`、打 tag。

## 已知边界

- 本工具只处理 TVBox 的结构性产物；小猫影视 `config.json` 与阅读模板不走这里。
- GitHub raw 有 CDN 缓存，推完立刻测到旧内容属正常延迟，用 `--ref <tag>` 复测（`规范/仓库通用规范.md` 10.1）。
