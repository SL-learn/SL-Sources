# 公开仓扫描 说明

位置：`工具/公开仓扫描/`｜条款依据：`规范/仓库通用规范.md` 私有域与文档分工章节。

## 作用

推送前最后一道门禁，拦两类问题：

1. **私有痕迹**：私有包名、私有目录、未共享提示词、维护侧元数据文件名、成人主体源文件。
2. **悬空引用**：文档里写了但仓库中不存在的路径或链接。

口径说明：**成人「分类」不构成阻断**。普通源配置里出现 `伦理片（成人）` 等分类名属正常发布内容；门禁只拦以成人内容为主体的**源文件**（文件名含「成人」的 json/csv/txt）、`私有域/` 目录内容、维护侧元数据与私有词表。

## 命令

```bash
python 工具/公开仓扫描/扫描.py --词表 <私有词表路径>
python 工具/公开仓扫描/扫描.py --词表 ... --根 <被测目录>
```

词表路径也可用环境变量 `SL_GATE_WORDS`。**词表属私有域，不入公开仓**，脚本内不内置任何私有词。

## 输出与退出码

| 情况 | 输出 | 退出码 |
|---|---|---|
| 无命中 | `结论：通过（私有痕迹 0，悬空引用 0）` | 0 |
| 有命中 | 逐条 `✗ 文件:行: 命中「词」 → 原文`，末尾 `结论：阻断` | 1 |
| 缺词表 | 提示「词表属私有域，不随仓库分发」 | 2 |

## 判据来源

- 命中词：私有词表（维护侧维护）。
- 文件级判据：
  - `*清单.csv`、`站点目录.*`、`探活明细*`、`词表*.txt|csv` 一律视为维护侧元数据，出现在公开仓即阻断。
  - 文件名含「成人」的 `.json`/`.csv`/`.txt` 视为成人主体源文件，阻断。
  - 路径中出现 `私有域/` 目录，阻断。
  - 正文出现成人分类名、`extra.category` 中的 `（成人）` 标注，**不阻断**。
- 悬空引用：Markdown 相对链接 + 反引号中的仓库路径；含 `<应用>`、`YYYY` 等占位符的路径跳过。

## 失败提示长什么样

```
私有痕迹命中：1
  ✗ 使用/某说明.md:12: 命中「<私有词>」 → 详见<私有文件>.csv
悬空引用：0

结论：阻断。公开仓不得出现私有内容痕迹或悬空引用。
```
