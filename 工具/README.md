# 工具（指针说明）

本仓不存放可执行脚本：生成、检测、校验脚本统一维护在工作区 `SL_TVBOX/工具/`，本目录只说明入口与用途，避免同一脚本两份并存后各自漂移。

| 子工具 | 用途 | 入口（工作区） |
|---|---|---|
| 源检测 | 对 tvbox / catmovie / reading 三类源做分段体检并落记录 | `工具/源检测/main.py` |
| 源生成 | 由并集源数据生成两侧成品 | `工具/源生成/生成.py` |
| 编号校验 | 校验规范条款编号连续、不重号 | `工具/编号校验/校验.py` |
| 公开仓扫描 | 提交前扫描本仓，拦截不公开内容与词表命中 | `工具/公开仓扫描/扫描.py` |
| 发布 | 渲染镜像、导出便携包 | `工具/发布/发布.ps1` |
| 阅读模板 | 书源与订阅源空白模板 | `工具/阅读模板/书源模板.json` |

运行方式：在工作区根执行 `python 工具/<子工具>/<入口> --help` 查看参数。脚本改动只落在工作区，不回写本仓。
