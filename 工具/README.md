# 工具（指针）

> 文档编号：D11｜性质：运行命令指针｜**脚本本体不在本仓**，在工作区 `SL_TVBOX/工具/`，避免同一脚本两份漂移

## 1. 脚本位置

| 目录 | 脚本 | 作用 |
|---|---|---|
| `工具/源生成/` | `生成.py`、`校验.py`、`重排.py` | 重建索引/全量单文件；本地与线上校验 |
| `工具/发布/` | `渲染.py`、`发布.ps1`、`导出云端.py` | 双平台地址渲染、双远端发布、便携版导出 |
| `工具/一致性校验/` | `校验.py` | 公开 ∪ 私有 = 并集、公开 ∩ 私有 = ∅ |
| `工具/公开仓扫描/` | `扫描.py` | 公开仓泄密词扫描 |
| `工具/编号校验/` | `校验.py` | 条款编号完整性 |

脚本通过环境变量 `SL_REPO` 指向本仓；未设置时默认取工作区同级 `SL_公开`。

## 2. 常用命令

```powershell
python 工具/源生成/生成.py --check
python 工具/源生成/生成.py
python 工具/源生成/校验.py --platform github
python 工具/发布/渲染.py --check --platform github
powershell -ExecutionPolicy Bypass -File 工具\发布\发布.ps1
python 工具/发布/导出云端.py
python 工具/一致性校验/校验.py --明细
```

## 3. 何时用哪个

| 场景 | 先跑 | 再跑 |
|---|---|---|
| 只改了站点 | `生成.py --check` | `生成.py` → `校验.py` |
| 要发布 | `渲染.py --check --platform <平台>` | `发布.ps1` |
| 只发便携包 | `生成.py --check` | `导出云端.py`（内含包内自检） |
| 核对两侧条数 | `一致性校验/校验.py` | 失败先修源，不改文档数字 |

机制细节见 `../发布/构建说明.md`；条款见 `../规范/仓库通用规范.md` 第 10 章。
