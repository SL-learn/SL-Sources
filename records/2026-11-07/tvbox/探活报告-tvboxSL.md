## 6. 实机故障处置：选线路后站点为空（2026-11-07，v1.0.1）

### 6.1 现象

用户实机反馈：填总入口后提示「找不到站源」，进「综合」等模块下没有任何站点；改用本地配置（整包拷到手机）后现象相同。

### 6.2 根因

索引里把含中文与空格的线路目录做了百分号编码，并采用 `./` 相对写法：

```json
{"urls":[{"name":"综合","url":"./SL%20%E7%BB%BC%E5%90%88%E7%BA%BF%E8%B7%AF/api.json"}]}
```

两条证据链：

1. **对照可用包**：`参考资料/TVBox-wuxierj/星微261018，本地包/tvboxTW/本地仓.txt`（用户实机可用的本地索引）写法是 `clan://localhost/tvboxTW/本地【…】/api.json`，**中文原样、无百分号编码**。
2. **客户端行为**：本地文件服务把请求路径原样拼到存储根，不做百分号解码（`RemoteServer.java:158-166`）。因此 `clan://localhost/tvboxSL/SL%20%E7%BB%BC…/api.json` 在手机上找不到文件 → 线路配置 404 → 该线路 `sites` 为空；在线场景同理，索引里的 `./` 依赖客户端相对解析，解析不出时同样取不到线路配置。两条路径最终都表现为「线路能选中、站点为空」。

### 6.3 修复

| 文件 | 改动 |
|---|---|
| `api_index.json` | 三条线路改**绝对 raw URL**，中文原样不编码 |
| `api_index_local.json`（新增） | 三条线路写 `clan://localhost/tvboxSL/<线路目录>/api.json`，供整包本地加载 |
| `api_all.json`（新增） | 三条线路 151 站合成一份；`api`/`jar`/`ext` 全部绝对 raw URL，`;md5;` 段不编码；`key` 与线路内完全一致 |
| `目录说明.txt` | 写清三个入口的适用场景与「路径不要用百分号编码」 |
| `README.md` | 新增 R-CLI-17、重写 R-NAM-13、新增 R-NAM-20/21 |
| 站点 `key` | **未改动**，与 v1.0.0 逐条一致 |

### 6.4 修复验证（脚本模拟客户端解析）

用 `verify_parse.py` 按客户端逻辑复现：索引解析 → 三条线路 → 站点必备字段（`key`/`type`/`api`）→ 相对引用还原为磁盘路径并检查存在。

| 线路 | 站点数 | 解析出 | 引用缺失 |
|---|---|---|---|
| SL 综合线路 | 123 | 123 | 0 |
| SL 少儿线路 | 17 | 17 | 0 |
| SL 长辈线路 | 11 | 11 | 0 |
| 合计 | 151 | 151 | 0 |

`api_all.json` 内 71 个包内引用（jar/js/py/ext）以 UA `okhttp/3.15` 拉取，全部 200；仅 3 条上游站点首页（非包内文件）不可达，属上游可用性，不影响配置加载。
