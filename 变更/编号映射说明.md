# 编号映射说明

本文说明全仓条款编号的重整规则、冻结制度与本次重整口径。逐条对照见同目录 `编号映射表.csv`。

## 1. 新编号规则

条款编号固定为 `<应用>-<类别>-<三位序号>`，例如 `TVB-CFG-001`。

| 应用码 | 适用对象 |
|---|---|
| `TVB` | TVBox 源（`规范/TVBox 源规范.md`、`使用/TVBox 使用说明.md`） |
| `CAT` | 小猫影视自建源（`规范/小猫影视源规范.md`） |
| `RBS` | 阅读书源（`规范/阅读源规范.md` §1–§16） |
| `RRS` | 阅读订阅源（`规范/阅读源规范.md` §17） |
| `SYS` | 跨应用通用规则（`规范/仓库通用规范.md`） |
| `DOC` | 文档与流程类条款（本仓库当前未单独使用，预留给仓库级文档治理） |

| 类别码 | 含义 |
|---|---|
| `NAM` | 命名 |
| `STR` | 结构与格式 |
| `CFG` | 配置字段 |
| `CLS` | 分类与分组 |
| `PRB` | 探活 |
| `VER` | 版本与校验 |
| `DIST` | 分发 |
| `SEC` | 非公开域与内容门禁 |
| `PRC` | 流程（范围、修复、验收、维护） |
| `DOC` | 文档自身管理 |

编号责任：

- 一份文档只负责本应用（或本模块）的编号段，不得在他应用文档中定义同段条款。
- 跨应用共用规则只放 `SYS` 段，不在各应用重复定义。
- 序号在每个（应用, 类别）段内按文档出现顺序从 `001` 递增，三位补零，段内不跳号。
- 阅读的书源与订阅源分属 `RBS`、`RRS` 两段，不得混用同一段编号。

## 2. 冻结规则

1. **发布即冻结**：编号一经写入本说明与映射表，不再变更、不复用、不回收。
2. **废弃占位**：条款废弃时保留原编号并在正文标注 `[废弃]`，禁止把该号让给新条款。
3. **只追加**：新增条款只能追加到本（应用, 类别）段末尾的下一号；不得插号、不得跳号。
4. **预留与空号**：确有预留或废弃时，必须在 `编号映射表.csv` 的备注列写明原因与范围，否则视为编号断档缺陷。
5. **迁移**：条款换文档时编号随之换段，旧编号记入映射表并标注「迁移」，旧号不再使用。
6. **跨文档引用只写编号**：引用方写新编号即可，不得复制条款正文（与 `SYS-DOC-001` 一致）。

上述制度同时以条款形式写入 `规范/仓库通用规范.md` 第 17 章（`SYS-DOC-004`～`SYS-DOC-007`）。

## 4. 特殊处置说明

### 4.1 重复编号拆分

`规范/TVBox 源规范.md` 第 11 章中，`R-GAT-06` 在 11.1 与 11.2 各出现一次、`R-GAT-07` 在 11.1 与 11.3 各出现一次，四条正文互不相同：

- 11.1 的 `R-GAT-06` → `TVB-SEC-004`；11.2 的 `R-GAT-06` → `TVB-SEC-008`
- 11.1 的 `R-GAT-07` → `TVB-SEC-005`；11.3 的 `R-GAT-07` → `TVB-SEC-009`

四条正文全部保留，未合并。映射表中该两条旧号各占一行，新编号列用「；」列出两个结果，处置记为「拆分」。

### 4.2 跨文档迁移

`R-NAM-22`（对外路径永久固定）与 `R-NAM-23`（版本只存在两处）本属仓库级规则，本次从 `规范/TVBox 源规范.md` 移入 `规范/仓库通用规范.md`：

- `R-NAM-22` → `SYS-DIST-001`（§3.4 对外路径冻结）
- `R-NAM-23` → `SYS-VER-011`（§10.1 版本与历史）

TVBox 文档中原两行已删除，正文按原意保留在仓库通用规范中，未改写规则内容。

### 4.3 同号异义

`R-CFG`、`R-VER`、`R-ACC`、`R-FIX`、`R-PROBE`、`R-NAME`、`R-BASE`、`R-DOC` 等前缀在 TVBox、小猫影视、阅读之间重复出现。本次按文档归属分别映射：TVBox 文档用 `TVB-*`，小猫影视文档用 `CAT-*`，阅读书源用 `RBS-*`，订阅源用 `RRS-*`；工具与规则文件按「文件所属应用」选择映射，不做全局字符串替换。
