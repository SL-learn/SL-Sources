# 小猫影视 使用说明

## 在线导入

配置地址填：

```
https://raw.githubusercontent.com/SL-learn/SL-Sources/main/apps/catmovie/config.json
```

## 本地导入

1. 下载 `config.json` 到手机任意目录。
2. 小猫影视 → 设置 → 配置地址 → 选择本地文件。

## 加载后看到什么

36 个点播源（极速 6、快速 6、慢速 3、间歇 21）与 6 条直播。源名前的档位表示实测速度，慢速与间歇源同样保留，可按需选择。每个源的分类按上游原样展示，成人分类排在该源分类末尾并带 `（成人）` 后缀。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 分类末尾有「（成人）」 | 正常，上游分类原样保留 | 不需要处理；不点即可 |
| 加载后没有源 | 地址填的是网页地址而非 raw | 用上面的 raw 地址，不要用 `github.com/.../blob/...` |
| 源能加载但无内容 | 上游临时不可用 | 换时间重试；连续 3 天不可用按 `规范/小猫影视源规范.md` 处理 |

## 说明

本包只含普通源。成人内容按「源」分流：以成人内容为主体的源不进入公开包，普通源内夹带的成人分类照常展示并置后标注。字段与门禁口径见 `规范/小猫影视源规范.md`。
