# 小猫影视 使用说明

## 在线导入

配置地址填：

```
https://raw.githubusercontent.com/SL-learn/SL-Sources/main/apps/catmovie/config.json
```

## 本地导入

1. 下载 `config.json` 到手机任意目录。
2. 小猫影视 → 设置 → 配置地址 → 选择本地文件。

## 加载后看到什么

19 个点播源与 6 条直播。全部经过四段实测：分类能解析、至少 2 个分类有片、详情有播放地址、首地址真能拉到视频数据，且连续 3 轮全通。源名前的档位只有 `极速`/`快速`/`标准`/`慢速` 四种，表示接口速度；本轮三端点耗时凑不齐均值的源不写档位，只显示内容名。排序先按播放流畅度（流畅 → 一般 → 卡），卡的源集中在列表后段。配置顶层的 `updateTime` 与同目录 `更新时间.txt` 记录最后更新时间。

播放判档口径：实测速率 ≥ 码率×2 为流畅，≥×1.5 为一般，低于×1.5、首片超 3 秒或 10 秒内断流 ≥2 次为卡。卡点若在源站 CDN 吞吐，客户端侧无法修复。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 部分源播放卡 | 源站 CDN 吞吐低于码率 | 换列表中判档为「流畅」的源；源侧无法修复 |
| 某个源时好时坏 | 上游间歇性超时 | 已移入观察池，等待多轮复测后再决定是否恢复 |
| 加载后没有源 | 地址填的是网页地址而非 raw | 用上面的 raw 地址，不要用 `github.com/.../blob/...` |
| 源能加载但无内容 | 上游临时不可用或空壳接口 | 换时间重试；连续 3 天不可用按 `规范/小猫影视源规范.md` 处理 |
