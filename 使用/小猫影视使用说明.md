# 小猫影视 使用说明

## 在线导入

配置地址填仓库根 `地址.md` 里「小猫影视」那一行，或直接复制根 `README.md`、`apps/catmovie/README.md` 地址块中的对应行（两平台并列，由渲染脚本生成）。仓库内路径固定为 `apps/catmovie/config.json`。

## 本地导入

1. 下载 `config.json` 到手机任意目录。
2. 小猫影视 → 设置 → 配置地址 → 选择本地文件。

## 加载后看到什么

19 个点播源与 4 条直播。点播全部经过四段实测：分类能解析、至少 2 个分类有片、详情有播放地址、首地址真能拉到视频数据。源名前的档位只有 `极速`/`快速`/`标准`/`慢速` 四种，表示接口速度；本轮三端点耗时凑不齐均值的源不写档位，只显示内容名。排序先按播放流畅度（流畅 → 一般 → 卡），卡的源集中在列表后段。配置顶层的 `updateTime` 与同目录 `更新时间.txt` 记录最后更新时间。

直播 4 条按「客户端能不能真播」排序：`卫视｜央视卫视` → `综合｜VBSKY综合` → `地方｜央卫港澳` → `综合｜APTV综合`。每条源都用客户端实测过 2 个 HTTPS 频道、20 秒有真实流量，不以主机侧能拉作为排序依据。电视页自动选中列表第一个频道，若该频道是 HTTP 地址可能长时间缓冲，手动切到同表 HTTPS 频道即可；单频道表现不代表整条源失效。

播放判档口径：实测速率 ≥ 码率×2 为流畅，≥×1.5 为一般，低于×1.5、首片超 3 秒或 10 秒内断流 ≥2 次为卡。卡点若在源站 CDN 吞吐，客户端侧无法修复。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 部分源播放卡 | 源站 CDN 吞吐低于码率 | 换列表中判档为「流畅」的源；源侧无法修复 |
| 某个源时好时坏 | 上游间歇性超时 | 已移入观察池，等待多轮复测后再决定是否恢复 |
| 加载后没有源 | 地址填的是网页地址而非 raw | 用上面的 raw 地址，不要用 `github.com/.../blob/...` |
| 源能加载但无内容 | 上游临时不可用或空壳接口 | 换时间重试；连续 3 天不可用按 `规范/小猫影视源规范.md` 处理 |

## 说明

本仓为公开子集，只发布公开源；完整清单与内部记录不随仓库发布。字段与门禁口径见 `规范/小猫影视源规范.md`；未收录源见 `记录/观察池/catmovie/观察池.md`。
