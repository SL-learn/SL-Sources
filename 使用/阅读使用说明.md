# 阅读 使用说明

仓库直接提供可导入的成品：`apps/reading/书源.json`（111 条）、`apps/reading/订阅源.json`（26 条）。本仓只收录公开子集。

## 书源

1. 下载或复制 `apps/reading/书源.json`。
2. 阅读 → 我的 → 书源管理 → 右上角菜单 → 本地导入，选该文件即可整包导入。
3. 导入顺序即 `customOrder` 顺序，靠前的优先。

## 订阅源

1. 下载或复制 `apps/reading/订阅源.json`。
2. 阅读 → 我的 → 订阅 → 右上角菜单 → 本地导入，选该文件。

## 在线地址

可直接复制的地址在仓库根 `README.md`、`apps/reading/README.md` 的地址块，以及 `地址.md`（两平台并列，由 `工具/发布/渲染.py` 从 `规则/平台地址.json` 生成）：

- 书源：`地址.md` → 一、GitHub 可直接填的地址 → 阅读书源（仓库内路径 `apps/reading/书源.json`）
- 订阅源：同表 → 阅读订阅源（仓库内路径 `apps/reading/订阅源.json`）
- 书源与订阅源是**两类分别导入**，两个地址各填一次。

中文文件名在原样地址里可能取不到，改用同表下方的百分号编码写法（`%E4%B9%A6%E6%BA%90.json`）。

Gitee 侧 `书源.json`、`订阅源.json` 返回 451（内容审核拦截），不列作可用地址；Gitee 用户请改用 GitHub 地址，或下载文件后本地导入。

## 自己新增条目

1. 复制 `工具/阅读模板/书源模板.json` 或 `工具/阅读模板/订阅源模板.json`。
2. 按 `规范/阅读书源校验规则.md`、`规范/阅读订阅源校验规则.md` 填字段。
3. 追加进现有数组，`customOrder` 顺延，保持从 1 连续。

## 注意

| 项 | 说明 |
|---|---|
| 只收录公开子集 | 公开文件由单一真源导出，非公开清单内容不在本仓 |
| 字段以源码为准 | 字段名与行号见 `da17bb2` 的 `BookSource.kt` / `RssSource.kt`，不要凭印象加字段 |
| JSON 编码 | UTF-8 无 BOM；带 BOM 可能导入失败 |
| 单对象与数组 | 单个源可直接是对象；多个必须是数组 |
| ♻️ 与验证码 | 名称带 ♻️ 的为间歇源，可重试；`书耽【验证码】` 需按提示过验证码 |
