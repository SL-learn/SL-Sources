# 阅读 使用说明

仓库直接提供可导入的成品：`apps/reading/书源.json`（115 条）、`apps/reading/订阅源.json`（27 条）。本地验证版另有 117 / 28 条，多出的 3 条成人域条目按合规要求不入公开仓。

## 书源

1. 下载或复制 `apps/reading/书源.json`。
2. 阅读 → 我的 → 书源管理 → 右上角菜单 → 本地导入，选该文件即可整包导入。
3. 导入顺序即 `customOrder` 顺序，靠前的优先。

## 订阅源

1. 下载或复制 `apps/reading/订阅源.json`。
2. 阅读 → 我的 → 订阅 → 右上角菜单 → 本地导入，选该文件。

## 在线地址

- 书源：`https://raw.githubusercontent.com/SL-learn/SL-Sources/main/apps/reading/%E4%B9%A6%E6%BA%90.json`
- 订阅源：`https://raw.githubusercontent.com/SL-learn/SL-Sources/main/apps/reading/%E8%AE%A2%E9%98%85%E6%BA%90.json`

## 自己新增条目

1. 复制 `apps/reading/模板/书源模板.json` 或 `apps/reading/模板/订阅源模板.json`。
2. 按 `apps/reading/校验/书源校验规则.md`、`apps/reading/校验/订阅源校验规则.md` 填字段。
3. 追加进现有数组，`customOrder` 顺延，保持从 1 连续。

## 注意

| 项 | 说明 |
|---|---|
| 成人源不入库 | 成人书源与订阅源只在本地私有目录维护，公开仓不收录 |
| 字段以源码为准 | 字段名与行号见 `da17bb2` 的 `BookSource.kt` / `RssSource.kt`，不要凭印象加字段 |
| JSON 编码 | UTF-8 无 BOM；带 BOM 可能导入失败 |
| 单对象与数组 | 单个源可直接是对象；多个必须是数组 |
| ♻️ 与验证码 | 名称带 ♻️ 的为间歇源，可重试；`书耽【验证码】` 需按提示过验证码 |
