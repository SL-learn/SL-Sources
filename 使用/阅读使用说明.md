# 阅读 使用说明

仓库不提供个人书源文件，只提供模板与校验规则。个人源需要自己按模板填，本地导入。

## 书源

1. 复制 `apps/reading/书源/模板.json`。
2. 按 `apps/reading/书源/校验规则.md` 填 `bookSourceUrl`、`bookSourceName`、`searchUrl` 与四条规则。
3. 保存为 `书源.json`（单个对象，或多个书源用 `[...]` 包成数组）。
4. 阅读 → 我的 → 书源管理 → 右上角菜单 → 本地导入。

## 订阅源

1. 复制 `apps/reading/订阅源/模板.json`。
2. 按 `apps/reading/订阅源/校验规则.md` 填 `sourceUrl`、`sourceName`、`ruleArticles`、`ruleTitle`、`ruleLink`。
3. 保存为 `订阅源.json`。
4. 阅读 → 我的 → 订阅 → 右上角菜单 → 本地导入。

## 注意

| 项 | 说明 |
|---|---|
| 不要提交个人源 | 含自用站点与登录信息，属个人数据 |
| 字段以源码为准 | 字段名与行号见 `da17bb2` 的 `BookSource.kt` / `RssSource.kt`，不要凭印象加字段 |
| JSON 编码 | UTF-8 无 BOM；带 BOM 可能导入失败 |
| 单对象与数组 | 单个源可直接是对象；多个必须是数组 |
