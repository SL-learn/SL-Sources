# 构建说明

> 文档编号：D10｜性质：机制说明｜实现脚本在仓外工作区 `工具/发布/`，本文件只写机制与门禁

## 1. 为什么分平台渲染

GitHub 与 Gitee 的 raw 基址不同（两平台各自域名，见 `规则/平台地址.json`），把 GitHub 地址原样推到 Gitee 会让整个配置不可用。因此：

- 基址只在 `规则/平台地址.json` 定义一处；
- `发布/地址.md` 与四个 README 的地址块由 `渲染.py` 生成，两平台并列；
- `apps/tvbox/api_index.json`、`apps/tvbox/api_all.json` 按平台渲染，其余文件两平台完全一致；
- GitHub 用 `main`；Gitee 由本地 `gitee` 分支整树重建后推 `gitee:main`。

强制条款见 `../规范/仓库通用规范.md` 第 3.5 节（SYS-DIST-002 ~ SYS-DIST-013）与第 10 章（SYS-VER-008/011）。

## 2. 渲染

```powershell
python 工具/发布/渲染.py --platform github
$env:GITEE_OWNER = "<你的 Gitee 个性地址>"
python 工具/发布/渲染.py --platform gitee
python 工具/发布/渲染.py --check --platform gitee
```

`渲染.py` 会：① 读 `规则/平台地址.json` → ② 调 `生成.py` 重算索引与全量单文件 → ③ 由 `发布/地址模板.md` 渲染 `发布/地址.md`，并把 README 地址块写入受管标记之间 → ④ 门禁：标记外不得出现写死的仓库绝对地址或另一平台域名；`地址.md` 必须含两平台基址且不把 451 路径当可用地址；README 地址块必须最新；**索引 `urls` 去重后长度必须等于线路数**。

受管块里的版本与条数从 `apps/*/version.json` 读取，不写死在脚本里（SYS-VER-002）。

## 3. 多线路索引（勿回退）

| 平台 | 综合 | 少儿 | 长辈 |
|---|---|---|---|
| GitHub | `std/api.json` | `kids/api.json` | `elders/api.json` |
| Gitee | `api_all.json`（合并文件） | `kids/api.json` | `elders/api.json` |

Gitee 对 `std/api.json` 返回 451，故综合线路改用 `api_all.json`。**三条 url 必须互不相同**：客户端按 url 区分线路且只缓存一份配置，统一指向同一文件会让「综合/少儿/长辈」切换后显示同一份列表（SYS-DIST-013）。合并文件含少儿/长辈重复站点，属合并固有形态，不算缺陷。

## 4. 发布与回退

```powershell
powershell -ExecutionPolicy Bypass -File 工具\发布\发布.ps1            # 两平台
powershell -ExecutionPolicy Bypass -File 工具\发布\发布.ps1 -Platform gitee -Tag
powershell -ExecutionPolicy Bypass -File 工具\发布\发布.ps1 -DryRun
```

- GitHub 线：临时 worktree 从 `main` 起 → 渲染 github 版 → 只提交受管产物 → `push origin HEAD:main`；
- Gitee 线：临时 worktree 基于本地 `gitee` → `git read-tree -u --reset main` 整树拉齐 → 渲染 gitee 版 → 校验差异恰为两个平台产物 → 提交快照 → `push gitee HEAD:main`；
- 全程禁止 force、禁止改写历史；Gitee 拉取带 `--no-tags`。

## 5. 便携版导出

```powershell
python 工具/发布/导出云端.py
```

导出：① 复制最小可运行集 → ② 自指绝对地址重写为 `./` → ③ 本地化运行时上游依赖并改相对引用 → ④ 分层扫描 → ⑤ 生成 `文件指纹.txt` 与 `地址-便携版.txt` → ⑥ 打 zip。

包内两条硬约束（导出后自检，失败即不出包）：

| 编号 | 约束 | 自检 |
|---|---|---|
| PKG-009 | 构建副产物不进包 | `__pycache__`、`.pyc/.pyo/.class/.bak/.log/.tmp` 计数为 0 |
| PKG-010 | 不以本机回环为运行时依赖 | `http://127.0.0.1`、`http://localhost`、`file:///`、`ftp://` 必须命中 `规则/包内白名单.json` 的逐文件逐行登记，否则判失败 |

`规则/包内白名单.json` 只登记 TVBox 客户端内置代理（9978 / 2525），不是通用豁免。

## 6. 验收

```powershell
python 工具/发布/渲染.py --check --platform github
python 工具/发布/渲染.py --check --platform gitee
python 工具/源生成/校验.py --platform github
python 工具/源生成/校验.py --platform gitee
python 工具/一致性校验/校验.py --明细
```

验收标准：两平台索引与三条线路均 200；逐线路站点数与 `version.json` 一致；`spider.jar` md5 一致；`cms.js` 200；一致性等式成立（公开 ∪ 私有 = 并集，公开 ∩ 私有 = ∅）。
